# Figure Forge Pricing

preciso de uma pagina baseada nessa e bonecos de impressao 3d
https://gaf-33-custom-figures.vercel.app/#inicio
mas com uma estimativa de preco de produto baseada em calculos acima do preco que o vendedor quer colocar de lucro 
Custo $ - Baseado em:

Preço estimado pra produzir o personagem, calculado em cima de:

Custo atual da resina gasta pra fazer um personagem com o tanto q vai gastar em liquido(L/ml) + um pequeno custo médio que faça sentido de gastos adicionais(como luz elétrica gasta, com a máquina ligada, álcool isopropílico para cura, suportes) + mão de obra média de fazer todo esse processo + um preço que faça sentido cobrar pela pintura, da pra fazer uma mais barata simples e uma detalhada mais cara
